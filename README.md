# Registration Form

A simple registration form created using HTML with inline Tailwind CSS and inline JavaScript.

## Features
- Responsive design using Tailwind CSS
- Form validation with inline JavaScript
- User-friendly input fields

## Technologies Used
- **HTML**: Structure of the form
- **Tailwind CSS (Inline)**: Styling for the form
- **JavaScript (Inline)**: Basic form validation

## Setup & Usage
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/registration-form.git
   ```
2. Open the `index.html` file in a browser to view the form.
